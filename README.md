---

## About Me

I am interested in how modern AI systems are built below the model API layer.

More specifically, I care about:

- how attention mechanisms are mapped onto hardware;
- how kernels are designed, tiled, optimized, and profiled;
- how runtime systems schedule computation and memory movement;
- how model architecture choices interact with system constraints;
- how efficient LLM training and inference systems are implemented in practice.

My long-term direction is **AI infrastructure and system-model co-design**, where algorithmic ideas are translated into efficient, scalable, and production-grade systems.
